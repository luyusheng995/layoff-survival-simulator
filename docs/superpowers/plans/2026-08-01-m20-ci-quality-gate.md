> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a GitHub Actions workflow that reruns the project's current quality gate on push and pull request.

**Architecture:** Keep workflow validation in `tests/game.test.js` as a repository contract. Keep browser executable discovery in `scripts/browser-smoke.mjs`, exporting no production API but testing the candidate list by reading the script text.

**Tech Stack:** GitHub Actions, Node.js 24, built-in test runner, headless Chrome/Edge CDP.

## Global Constraints

- Do not add npm dependencies.
- Do not make CI deploy or publish the game.
- Keep release artifacts generated by `npm run release`.
