# 大厂裁员生存模拟器配置交付文档

版本：0.1.0

## 核心玩法

- 赛道定位：职场情绪向文字生存游戏
- 商业化：纯激励视频广告
- 周期：90 天
- 每日精力：3 点
- 行动类型：加班干活、摸鱼划水、向上管理、抱团站队、副业赚钱

## 核心数值

| 数值 | 初始值 | 下限 | 上限 |
| --- | ---: | ---: | ---: |
| performance | 60 | 0 | 100 |
| hair | 80 | 0 | 100 |
| dignity | 70 | 0 | 100 |
| savings | 5000 | 无限 | 无限 |

## 事件库

总计 200 条：日常 140 条、危机 40 条、机遇 20 条。

## 广告点位

- 死亡复活（revive）：恢复核心数值到安全线，继续打工
- 每日 Buff（dailyBuff）：当天摸鱼不扣绩效
- 天赋解锁（talentUnlock）：开放 3 个开局天赋
- 查看结局（endingPreview）：显示未解锁结局条件
- 跳过负面事件（skipCrisis）：规避当前危机事件惩罚

## 结局体系

共 12 种结局。
- 试用期被优化（fired_performance）：绩效分降到 0。
- 身体垮掉主动离职（hair_collapse）：发量值降到 0。
- 心态崩溃裸辞（quit_naked）：尊严值降到 0。
- 交不起房租被迫回老家（home_rent）：存款额降到 0 或以下。
- 撑到年底拿年终奖（year_bonus）：撑到第 90 天，绩效不低且身体还没崩。
- 反向晋升为管理层（reverse_promoted）：第 90 天绩效 >= 90、尊严 >= 40、存款 >= 20000。
- 副业上岸体面离场（side_hustle_escape）：第 90 天存款 >= 50000。
- 转岗成功继续拧螺丝（internal_transfer）：保持中高尊严并触发转岗/内推路线。
- N+1 体面毕业（n_plus_one）：HR 约谈中争取赔偿并安全离场。
- 上市敲钟合伙人（ppt_partner）：PPT/汇报路线高频成功，且绩效维持高位。
- 沉默幸存者（silent_survivor）：撑到第 90 天但未达成特殊结局。
- 背包自由职业者（backpack_freelancer）：副业和尊严都较高，选择自由职业路线。

## 难度配置

- 普通牛马：裁员评估 x1，危机权重 x1
- 绩效背锅人：裁员评估 x1.35，危机权重 x1.35
- 裁员重灾区：裁员评估 x1.75，危机权重 x1.7

## 平衡目标

- averageDays: 65-80
- reviveRate: 0.15-0.40
- failureRate: 0.10-0.35
- failureVariety: >=3 hard-failure ending types
